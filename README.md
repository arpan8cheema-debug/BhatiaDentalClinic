# Bhatia Dental Clinic Netlify Project

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Netlify

1. Push this folder to GitHub.
2. In Netlify, choose **Add new project**.
3. Import the GitHub repo.
4. Netlify settings:
   - Build command: `npm run build`
   - Publish directory: `dist`
5. Deploy.

`netlify.toml` is already included for SPA routing.
